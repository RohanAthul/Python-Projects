# Rock Paper Scissors Game

Classic command-line implementation of the "Rock, Paper, Scissors" hand game. This Python script allows a user to play against a computer that makes randomized choices.

## Description

Project showcases the use of ASCII art and randomized logic to build an engaging terminal game while focusing on several core programming pillars:

- List Indexing: Using a list to store and retrieve large strings (ASCII art)

- Randomization: Utilizing the random module to simulate a computer opponent

- Complex Conditionals: Evaluating multiple win/loss scenarios using if, elif, and else

- Input Validation: Handling numeric user input and identifying invalid entries

## The Game Rules

The logic follows the traditional hierarchy:

- Rock beats Scissors

- Paper beats Rock

- Scissors beats Paper

- Matching choices result in a Draw.

## Running the App

The script is cross-platform and will run on Windows, macOS, and Linux.
